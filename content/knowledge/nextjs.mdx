# How an entry reaches a Knowledge Hub page

An entry in this repository starts as a file under one of four content directories. Its category and filename select the reading URL; its frontmatter supplies the title, date, description and tags.

## Follow one entry
A file named `content/knowledge/big-integer-inputs.mdx` is read at `/knowledge/big-integer-inputs`. The route asks `getEntryBySlug` in `lib/mdx.ts` for that category and slug. The loader reads the file and separates frontmatter from its body with gray-matter.

The shared `renderEntry` helper converts the Markdown body to HTML with remark and remark-html. The page places the metadata above that body. Ordinary Markdown headings, links, lists and fenced examples are supported in these reading views.

## Author for this path
Keep the filename stable when revising an existing entry so inbound URLs keep working. Use a quoted ISO date in frontmatter. Choose a description that tells a reader what they can learn rather than repeating the title.

The files are deliberately a curated public collection. The loader is not connected to a private knowledge base or an automatic diary exporter. Before adding material, follow the [publication policy](/docs/publication-policy). Changing rendering behavior or adding executable MDX components needs separate code review.

Implementation references: `lib/mdx.ts` and `lib/render-entry.ts` in this repository; [remark-html](https://github.com/remarkjs/remark-html).
